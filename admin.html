Админка меню

Здесь меняются цены, блюда, фото и стоп-лист. Изменения сохраняются в GitHub, и сайт обновляется сам.

Как получить ключ доступа
  1. Зайдите на GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Срок действия — например, 1 год. В Repository access выберите только репозиторий с сайтом.
  3. В Permissions → Repository permissions → Contents выберите Read and write.
  4. Нажмите Generate token, скопируйте ключ и вставьте сюда. Он хранится только в этом браузере.

Никому не передавайте ключ: с ним можно менять сайт.
