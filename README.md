# Aisha — семейное кафе · QR-меню

Электронное меню для гостей на казахском и русском языках. Открывается по QR-коду на столе.

## Страницы
- `index.html` — меню для гостей: переключатель ҚАЗ / РУС, поиск, «Мой заказ» с подсчётом суммы и отправкой в WhatsApp.
- `admin.html` — админка для владельца: цены, блюда, фото, стоп-лист, контакты.
- `qr.html` — генератор QR-кода с логотипом для печати на столы.

## Где лежит меню
Все блюда, цены и контакты — в `data/menu.json`. Обычно его не нужно править руками: для этого есть админка.
Фото блюд, загруженные через админку, сохраняются в `img/dishes/`.

## Админка
1. Опубликуйте сайт на GitHub Pages (см. ниже) и откройте `https://<логин>.github.io/<репозиторий>/admin.html`.
2. Создайте ключ доступа: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: только этот репозиторий.
   - Permissions → Contents: **Read and write**.
3. Вставьте ключ в админку и нажмите «Войти». Ключ хранится только в этом браузере.
4. Меняйте что нужно и нажимайте «Сохранить». Сайт обновится через 1–2 минуты.

Без ключа можно открыть админку в демо-режиме: всё работает, но на сайт не сохраняется.

## Публикация (бесплатно, GitHub Pages)
1. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
2. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
3. Откройте `.../qr.html`, проверьте адрес и распечатайте QR-коды для столов.

QR-код ведёт на постоянный адрес, поэтому после изменения меню перепечатывать его не нужно.
