# Aisha — семейное кафе · QR-меню

Электронное меню для гостей на казахском и русском языках. Открывается по QR-коду на столе.

## Страницы
- `index.html` — меню для гостей: переключатель ҚАЗ / РУС, поиск, «Мой заказ» с подсчётом суммы и отправкой в WhatsApp.
- `admin.html` — админка для владельца: цены, блюда, фото, стоп-лист, контакты.
- `qr.html` — генератор QR-кода с логотипом для печати на столы.

## Где лежит меню
Все блюда, цены и контакты — в `data/menu.json`. Обычно его не нужно править руками: для этого есть админка.
Фото блюд, загруженные через админку, сохраняются в `img/dishes/`.

## Админка
Адрес: `https://<логин>.github.io/<репозиторий>/admin.html`.

**Клиент входит по логину и паролю.** Логины создаёт разработчик:
1. Создайте ключ доступа: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   Repository access — только этот репозиторий; Permissions → Contents: **Read and write**.
2. В админке нажмите «Вход для разработчика (по ключу GitHub)» и войдите с ключом.
3. Вкладка **«Доступ»** → придумайте логин и пароль (от 8 символов) → «Сохранить логин».
   Через 1–2 минуты по ним можно входить с любого телефона.

Как это устроено: ключ GitHub хранится в `data/admin-auth.json` только в зашифрованном виде
(AES-GCM; ключ шифрования защищён паролем через PBKDF2-SHA256, 600 000 итераций).
Файл публичный, поэтому пароль должен быть надёжным.

**Когда ключ GitHub истечёт:** создайте новый ключ, войдите с ним как разработчик и во вкладке «Доступ»
подтвердите любой существующий логин — пароли клиентов снова заработают. Пока ключ действует,
его можно заменить там же, в поле «Новый ключ».

Без входа админку можно открыть в демо-режиме: всё работает, но на сайт не сохраняется.

## Публикация (бесплатно, GitHub Pages)
1. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
2. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
3. Откройте `.../qr.html`, проверьте адрес и распечатайте QR-коды для столов.

QR-код ведёт на постоянный адрес, поэтому после изменения меню перепечатывать его не нужно.
