# Aisha — семейное кафе · QR-меню

Электронное меню для гостей: открывается по QR-коду на столе, без установки приложений.

## Что внутри
- `index.html` — само меню: категории, поиск, метки «Хит / Новинка / Острое», «Мой заказ» с подсчётом суммы и отправкой в WhatsApp.
- `qr.html` — генератор QR-кода с логотипом: можно указать номер стола, скачать PNG или распечатать карточку.
- `js/menu-data.js` — **все блюда, цены и контакты**. Меню редактируется только здесь.
- `img/logo.png` — логотип. Фото блюд кладите в `img/dishes/` и указывайте в поле `img`.

## Как изменить меню
Откройте `js/menu-data.js` и поменяйте названия, описания, цены. Чтобы временно скрыть блюдо из продажи — добавьте `off: true`.
В блоке `CAFE` замените телефон, WhatsApp, адрес и часы работы.

## Публикация (бесплатно, GitHub Pages)
1. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
2. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
3. Откройте `.../qr.html`, проверьте адрес и распечатайте QR-коды для столов.

QR-код ведёт на постоянный адрес, поэтому после изменения меню перепечатывать его не нужно.
